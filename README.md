#  Library Manager

Консольное приложение для управления домашней библиотекой, написанное на Python.

## Возможности

-  Добавление новой книги
-  Просмотр всех книг
-  Поиск книги по названию
-  Удаление книги
-  Автоматическое сохранение данных в JSON
-  Загрузка библиотеки при запуске программы

## Используемые технологии

- Python 3
- JSON
- Функции
- Списки словарей
- Работа с файлами

## Структура проекта

```
LibraryManager/
│
├── library.py
├── text_tools.py
├── book.json
└── README.md
```

## Как запустить

1. Склонировать репозиторий.
2. Открыть папку проекта.
3. Запустить:

```bash
python library.py
```
